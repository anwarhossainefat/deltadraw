EDFA = {⟨A⟩ | L(A) = ∅}

The decider marks the start state, then keeps marking any state with an arrow coming in from a marked state. A accepts some string exactly when an accepting state gets marked (Theorem 4.4).

EQDFA = {⟨A, B⟩ | L(A) = L(B)}

The decider builds C that accepts the strings where A and B disagree, and runs the EDFA decider on C (Theorem 4.5).

ECFG = {⟨G⟩ | L(G) = ∅}

The decider marks every terminal, then marks a variable A whenever some rule A → U1⋯Uk has every Ui marked. L(G) is empty exactly when the start variable is never marked (Theorem 4.8).

The Post Correspondence Problem

A match is a sequence of dominoes, repeats allowed, whose top row and bottom row spell the same string. Deciding whether a set of dominoes has a match is undecidable (Theorem 5.15), so this puzzle has no general algorithm. Try it by hand, then let the computer search.

One domino per line: top / bottom.

Why a search cannot always decide

A program can try sequences of 1, 2, 3, … dominoes and stop when it finds a match, so PCP is Turing-recognizable. But when there is no match the search may never end, and Sipser shows (by reducing ATM to PCP) that no program can always tell the two cases apart.

Decidability, step by step

Chapter 4 of Sipser asks which questions about machines an algorithm can answer. Some can be decided by simple marking procedures; others, like whether a Turing machine accepts a string, cannot be decided at all. This page lets you run the deciders, follow the diagonal proofs, and play with an undecidable puzzle.

Deciders

  1. A decider is a Turing machine that halts on every input, answering accept or reject.
  2. EDFA and ECFG are decided by marking: keep marking until nothing changes, then look at what got marked.
  3. EQDFA reduces to EDFA: two machines agree exactly when the machine for their symmetric difference accepts nothing.

Undecidable problems

  1. The diagonal method builds an object that differs from every item in a list.
  2. Applied to Turing machines, it gives a machine D that disagrees with itself, so ATM has no decider.
  3. Chapter 5 spreads this result by reductions: HALTTM, ETM, EQTM and PCP are undecidable too.
